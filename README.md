# 📊 T-Invest Portfolio Tracker

> **Умная ребалансировка с учётом лотов. Реализованный пассивный доход. Полноценная история, календарь выплат, health-check и XIRR — всё в одной таблице.**

Работает прямо в **Google Sheets** и синхронизируется через **T-Invest API**.

> 💡 **По умолчанию использует прокси Relferium** — новичкам не нужно бороться с SSL-ошибкой Т-Банка. Если хочешь свой прокси — просто замени одну строку в коде или задай `PROXY_URL` в Script Properties.

---

## ✨ Возможности

### 💰 Умная ребалансировка с учётом лотов
Алгоритм распределяет бюджет пропорционально дефициту, округляет до целых лотов и отдаёт остаток самым отстающим бумагам.

### 🏦 Честный учёт пассивного дохода
Купоны и дивиденды считаются отдельно от возврата номинала. Прогноз дивидендов по CAGR, Payout Ratio со светофором.

### 📅 Календарь выплат
Точные даты купонов через `GetBondCoupons`. Ближайшие 7 дней выделяются жёлтым.

### 📋 История операций
Все операции за 12 месяцев с пагинацией. Сводка: пополнения, выводы, комиссии, реализованный доход.

### 📈 XIRR и сравнение с IMOEX
Доходность с учётом дат пополнений. Можно задать дату начала расчёта. Реальная доходность с поправкой на инфляцию.

### 💵 Учёт наличных и денежных активов вне брокера
Отдельный журнал для USD, EUR, вкладов и других денежных активов. Автоматическая сводка с P/L. Не влияет на расчёт XIRR инвестиционного портфеля.

### 🩺 Health-check концентрации
Доля крупнейшей позиции и топ-3. Индекс Херфиндаля и «эффективное число позиций».

### 🎯 Прогресс к цели
Прогноз даты достижения целевой суммы по текущему XIRR и дисциплине пополнений.

### 🏦 ИИС-3
Отслеживание годового лимита вычета (400 000 ₽) и минимального срока владения счётом.

### 📄 HTML-дашборд
Интерактивные графики Chart.js: распределение, радар «Факт vs Цель», рост портфеля, P/L по акциям, сектора, доход по месяцам.

### 🤖 Telegram-бот
Меню 2×2: ребаланс, статус, ИИС-3, концентрация. Команды `/status`, `/iis`, `/health`, `/pl`.

## 🚀 Быстрый старт

1. Скопируй таблицу
2. В Apps Script задай `TINKOFF_TOKEN` (токен только на чтение)
3. Запусти `Tinkoff → 🔄 Синхронизировать позиции`

Прокси уже встроен — дополнительно ничего настраивать не нужно.

📖 Подробная инструкция — в [`INSTALLATION.md`](INSTALLATION.md).

# Деплой-скрипты

Скрипты для деплоя изменений из `Code/` напрямую в Google Apps Script
через [`clasp`](https://github.com/google/clasp), вместо ручного
копирования файлов в редактор Apps Script.

## Требования

1. Установленный `clasp`:
   ```bash
   npm install -g @google/clasp
   ```
2. Авторизация:
   ```bash
   clasp login
   ```

## Как использовать

1. Найди Script ID своей копии таблицы: открой её → **Extensions → Apps
   Script → ⚙️ Настройки проекта → Script ID**.
2. В корне репозитория создай свой конфиг, например `.clasp.json` (или
   `.clasp.template.json` по аналогии с `push-template.sh`, если хочешь
   несколько сценариев — тогда переименуй копию `push-template.sh` под свой
   вариант и поправь в ней имя файла конфига):
   ```json
   {
     "scriptId": "ТВОЙ_SCRIPT_ID",
     "rootDir": "./Code"
   }
   ```
3. Запусти:
   ```bash
   ./scripts/push-template.sh
   ```
   (или переименованную под свой сценарий копию).

## Перед первым пушем — сверься

**Перед тем как пушить, обязательно сверь состояние своей копии скрипта** —
`clasp pull` в отдельную папку или ручное сравнение файлов. `clasp push`
перезаписывает содержимое скрипта на сервере файлами из `Code/` без
предупреждения — если в твоей копии есть несохранённые сюда правки
(например, сделанные прямо в редакторе Apps Script), они будут потеряны.

# 📦 Установка T-Invest Portfolio Tracker

Два способа — быстрый (рекомендуется) и ручной (если хотите собрать код руками из GitHub, например для собственного форка).

---

## Способ 1 — через шаблон (рекомендуется)

Весь код (все 22 файла) уже лежит в готовой таблице — просто сделайте свою копию, и Google Sheets перенесёт код автоматически. Токены, триггеры и данные при копировании **не переносятся** — это не баг, а особенность Google: каждая копия требует собственной авторизации. Именно поэтому это безопасно — ваша копия полностью независима от чужой.

### Шаг 1 — Скопируйте шаблон

1. Откройте [шаблон-таблицу](https://docs.google.com/spreadsheets/d/1aIhto-GZo2R68mEy-P14DBg-LlApNJBH1eRl3Fc70fs/edit?usp=sharing)
2. **Файл → Создать копию**
3. Готово — у вас своя таблица со всем кодом внутри, но без данных и настроек

### Шаг 2 — Токен T-Invest API

1. В приложении Т-Банка: **Инвестиции → Настройки → Токен для OpenAPI**
2. Выпустите токен с правами **«Только чтение»** — этого достаточно для всего функционала трекера
3. В своей копии таблицы: **Расширения → Apps Script**
4. ![](screenshots/11.png) Слева — значок **⚙️ Настройки проекта**
5. ![](screenshots/12.png) Прокрутите вниз до разделов «Идентификатор скрипта», «Проект Google Cloud Platform» и «Свойства скрипта»
6. ![](screenshots/13.png) В «Свойствах скрипта» нажмите «Добавить свойство скрипта» — появятся пустые поля «Свойство» / «Значение»
7. ![](screenshots/14.png) Имя: `TINKOFF_TOKEN`, значение — ваш токен → **Сохранить свойства скрипта**

### Шаг 3 — Триггеры автообновления

В том же Apps Script слева — значок **⏰ Триггеры**.

1. ![](screenshots/15.png) Список пока пуст → «+ Добавить триггер»
2. ![](screenshots/16.png) Функция `syncAndRefresh`, источник «Триггер по времени», тип «По дням», время — любое удобное окно, например 23:00–0:00. **На этом шаге Google запросит разрешения для скрипта — это нормально, подтвердите доступ.**
3. ![](screenshots/17.png) Добавьте второй триггер тем же способом: функция `recordDailySnapshot`, то же время
4. ![](screenshots/18.png) В списке должно быть **2** триггера — `syncAndRefresh` и `recordDailySnapshot`

### Шаг 4 — Первый запуск

1. Обновите страницу таблицы (F5) — в строке меню появится пункт **Tinkoff**. Если не появился — обновите ещё раз.
2. ![](screenshots/20.png) Так должно выглядеть — меню Tinkoff со всеми пунктами прямо в таблице
3. Запустите по порядку:
   ```
   Tinkoff → ⚙️ Настройки → Инициализировать Config
   Tinkoff → 🚀 Синхронизировать + обновить всё
   ```
4. Настройте стратегию на листе **Настройки** — см. раздел [«Настройка стратегии»](README.md#-настройка-стратегии) в README, либо подробный разбор со скриншотами ниже.

Готово — трекер настроен и работает.

## Заполнение Config — пошагово со скриншотами

Не зависит от того, каким способом ставили код (шаблон или вручную) — эта часть всегда одинаковая.

1. ![](screenshots/21.png) В меню **Tinkoff → Настройки → Инициализировать Config** — создаётся лист «Настройки» с заготовками всех блоков.
2. ![](screenshots/22.png) Так выглядит свежесозданный Config: целевая структура портфеля, целевые доли акций, маппинг спецкатегорий, дивиденды, продвинутые параметры, цель портфеля — все поля пустые/дефолтные.
3. ![](screenshots/23.png) Заполните блок «Целевая структура портфеля»: проценты по категориям (например, Акции 60 / Облигации 25 / Золото 10 / Замещайки 0 / Денежный рынок 5) и названия счетов.
4. ![](screenshots/24.png) В меню **Tinkoff → Синхронизировать + обновить всё** — подтягиваются реальные позиции из Т-Инвестиций.
5. ![](screenshots/25.png) Через правый клик по ярлычкам листов внизу можно увидеть скрытые технические листы: `_Позиции`, `_Дан_Акции`, `_Дан_Облигации`, `_Дан_Фонды` и т.д. — в них реальные данные по вашим бумагам.
6. ![](screenshots/26.png) Откройте `_Дан_Акции` — там точные названия акций из вашего портфеля (это нужно для следующего шага).
7. ![](screenshots/27.png) Впишите эти названия **точно как в `_Дан_Акции`** в блок «Целевые доли акций» в Config (колонка «Тикер» — тикер соответствующей бумаги).
8. ![](screenshots/28.png) Проверьте, что название и тикер (например, «Озон» / `OZON`) введены без опечаток.
9. ![](screenshots/29.png) Аналогично откройте `_Дан_Фонды`, чтобы найти точное название фонда золота и денежного рынка.
10. ![](screenshots/30.png) В `_Дан_Фонды` — например, `ВИМ – Фонд Золото` и `Денежный рынок` с их тикерами (`GOLD`, `TMON@`).
11. ![](screenshots/31.png) Заполните блок «Маппинг спецкатегорий» этими точными названиями (Золото → `ВИМ – Фонд Золото`, Денежный рынок → `Денежный рынок`), доцените целевые % по акциям и, если нужно, впишите целевую сумму портфеля в блок «Цель портфеля».

## Первое использование — пошагово со скриншотами

1. ![](screenshots/32.png) Config полностью заполнен — можно переходить к отчётам. Меню **Tinkoff → Дашборд и ребаланс** открыто для справки.
2. ![](screenshots/33.png) **Tinkoff → Доход и история → Обновить Календарь выплат.**
3. ![](screenshots/34.png) **Tinkoff → Доход и история → Обновить Историю операций** — это самый долгий запрос, наберитесь терпения.
4. ![](screenshots/35.png) Лист «История операций» заполнен реальными суммами (пополнения, купоны, дивиденды, сделки).
5. ![](screenshots/36.png) **Tinkoff → Отчёты** — отсюда можно сформировать годовой отчёт (Google Doc) или открыть HTML-дашборд.
6. ![](screenshots/37.png) HTML-дашборд открывается модальным окном: общая стоимость, XIRR, сравнение с IMOEX, круговая диаграмма по классам активов.
7. ![](screenshots/38.png) На листе «Ребалансировка» впишите сумму пополнения (например, 45 000 ₽) и запустите **Tinkoff → Дашборд и ребаланс → Пересчитать калькулятор пополнения**.
8. ![](screenshots/39.png) Калькулятор покажет, сколько и чего докупить, чтобы вернуться к целевым долям — с разбивкой по классам, по акциям и по лотам.

Если хотите собрать проект своими руками (например, форкнули репозиторий и вносите правки) — создаёте пустую таблицу, **Расширения → Apps Script**, и создаёте каждый файл из папки [`Code/`](Code/) вручную, копируя код. Дальше — те же шаги 2-4 из Способа 1 выше (токен, триггеры, первый запуск).

## 🤖 Отдельно — Telegram-бот (опционально)

Уведомления и интерактивное меню с ребалансировкой через Telegram настраиваются отдельно, уже после основной установки:

1. Создайте бота через [@BotFather](https://t.me/BotFather): `/newbot`, придумайте имя и username, получите токен
2. Найдите свой `chat_id` — откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` после того, как напишете боту `/start`, найдите `"chat":{"id": ...}` в ответе
3. В Свойствах скрипта (там же, где `TINKOFF_TOKEN`) добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
4. Проверьте: **Tinkoff → Настройки → Проверить подключение Telegram**
5. Для интерактивного меню (`/menu` → «Ребаланс») добавьте ещё один триггер: функция `checkTelegramUpdates`, «По времени», «По минутам», каждую 1 минуту — без этого сработают только пассивные уведомления (синхронизация, отклонения 5/25, купоны/дивиденды за неделю), но не меню с командами

> Ответ бота приходит не мгновенно — сама проверка внутри одного срабатывания триггера крутится циклом с паузами ~5 секунд в течение минуты, так что реальная задержка обычно в районе 2-5 секунд, а не целую минуту. Это осознанный компромисс: чуть медленнее, зато не требует деплоя веб-приложения и связанной с ним возни с URL.

# 📦 Установка T-Invest Portfolio Tracker

Два способа — быстрый (рекомендуется) и ручной (если хотите собрать код руками из GitHub, например для собственного форка).

---

## Способ 1 — через шаблон (рекомендуется)

Весь код (все 22 файла) уже лежит в готовой таблице — просто сделайте свою копию, и Google Sheets перенесёт код автоматически. Токены, триггеры и данные при копировании **не переносятся** — это не баг, а особенность Google: каждая копия требует собственной авторизации. Именно поэтому это безопасно — ваша копия полностью независима от чужой.

### Шаг 1 — Скопируйте шаблон

1. Откройте [шаблон-таблицу](https://docs.google.com/spreadsheets/d/1aIhto-GZo2R68mEy-P14DBg-LlApNJBH1eRl3Fc70fs/edit?usp=sharing)
2. **Файл → Создать копию**
3. Готово — у вас своя таблица со всем кодом внутри, но без данных и настроек

### Шаг 2 — Токен T-Invest API

1. В приложении Т-Банка: **Инвестиции → Настройки → Токен для OpenAPI**
2. Выпустите токен с правами **«Только чтение»** — этого достаточно для всего функционала трекера
3. В своей копии таблицы: **Расширения → Apps Script**
4. Слева — значок **⚙️ Настройки проекта → Свойства скрипта → Добавить свойство скрипта**
5. Имя: `TINKOFF_TOKEN`, значение — ваш токен → **Сохранить свойства скрипта**

### Шаг 3 — Триггеры автообновления

В том же Apps Script слева — значок **⏰ Триггеры → + Добавить триггер**. Добавьте два:

| Функция | Источник события | Тип | Время |
|---|---|---|---|
| `syncAndRefresh` | Время | По дням | любое удобное окно, например 23:00–0:00 |
| `recordDailySnapshot` | Время | По дням | то же окно |

При добавлении первого триггера Google запросит разрешения для скрипта — это ожидаемо, подтвердите доступ.

### Шаг 4 — Первый запуск

1. Обновите страницу таблицы (F5) — в строке меню появится пункт **Tinkoff**. Если не появился — обновите ещё раз.
2. Запустите по порядку:
   ```
   Tinkoff → ⚙️ Настройки → Инициализировать Config
   Tinkoff → 🚀 Синхронизировать + обновить всё
   ```
3. Настройте стратегию на листе **Настройки** — см. раздел [«Настройка стратегии»](README.md#-настройка-стратегии) в README.

Готово — трекер настроен и работает.

## Способ 2 — вручную из GitHub

Если хотите собрать проект своими руками (например, форкнули репозиторий и вносите правки) — создаёте пустую таблицу, **Расширения → Apps Script**, и создаёте каждый файл из папки [`Code/`](Code/) вручную, копируя код. Дальше — те же шаги 2-4 из Способа 1 выше (токен, триггеры, первый запуск).

## 🤖 Отдельно — Telegram-бот (опционально)

Уведомления и интерактивное меню с ребалансировкой через Telegram настраиваются отдельно, уже после основной установки:

1. Создайте бота через [@BotFather](https://t.me/BotFather): `/newbot`, придумайте имя и username, получите токен
2. Найдите свой `chat_id` — откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` после того, как напишете боту `/start`, найдите `"chat":{"id": ...}` в ответе
3. В Свойствах скрипта (там же, где `TINKOFF_TOKEN`) добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
4. Проверьте: **Tinkoff → Настройки → Проверить подключение Telegram**
5. Для интерактивного меню (`/menu` → «Ребаланс») добавьте ещё один триггер: функция `checkTelegramUpdates`, «По времени», «По минутам», каждую 1 минуту — без этого сработают только пассивные уведомления (синхронизация, отклонения 5/25, купоны/дивиденды за неделю), но не меню с командами

> Ответ бота приходит не мгновенно — сама проверка внутри одного срабатывания триггера крутится циклом с паузами ~5 секунд в течение минуты, так что реальная задержка обычно в районе 2-5 секунд, а не целую минуту. Это осознанный компромисс: чуть медленнее, зато не требует деплоя веб-приложения и связанной с ним возни с URL.

## Установка

### Этап 1. Создание проекта Apps Script и перенос кода (шаги 1–10)

1. ![](screenshots/1.png) Создайте новую пустую Google Таблицу.
2. ![](screenshots/2.png) Откройте **Расширения → Apps Script**.
3. ![](screenshots/3.png) Откроется новый проект Apps Script с одним файлом `Код.gs` и заглушкой `function myFunction() {}`.
4. ![](screenshots/4.png) Для ориентира — так выглядит структура папки `Code` в репозитории: в ней около 20 файлов `.js`, каждый нужно будет перенести отдельным файлом в Apps Script.
5. ![](screenshots/5.png) В папке `Code` на компьютере скопируйте имя очередного файла (без расширения `.js`) — оно понадобится для названия файла в Apps Script.
6. ![](screenshots/6.png) В Apps Script нажмите **⋮ → Переименовать** на `Код.gs` и присвойте ему имя первого файла (например, `advparams`).
7. ![](screenshots/7.png) Откройте соответствующий файл `.js` из папки `Code` (например, в VS Code) и скопируйте весь его код.
8. ![](screenshots/8.png) Файл в Apps Script уже переименован, но код в нём — ещё старая заглушка `myFunction()`.
9. ![](screenshots/9.png) Вставьте скопированный код поверх заглушки.
10. ![](screenshots/10.png) Сохраните проект (иконка дискеты / «Сохранить проект на Диск»).

> Повторите шаги 5–10 для каждого файла из папки `Code` (**+** рядом с «Файлы» → «Название файла» для каждого нового файла, кроме первого — он получается переименованием исходного `Код.gs`).

### Этап 2. Токен, триггеры, первый запуск (шаги 11–20)

11. ![](screenshots/11.png) Когда весь код перенесён, откройте **⚙️ Настройки проекта** (шестерёнка слева).
12. ![](screenshots/12.png) Прокрутите вниз до разделов «Идентификатор скрипта», «Проект Google Cloud Platform» и «Свойства скрипта».
13. ![](screenshots/13.png) В «Свойствах скрипта» нажмите «Добавить свойство скрипта» — появятся пустые поля «Свойство» / «Значение».
14. ![](screenshots/14.png) Впишите `TINKOFF_TOKEN` в поле «Свойство» и вставьте свой API-токен от Т-Инвестиций в поле «Значение» → «Сохранить свойства скрипта».
15. ![](screenshots/15.png) Перейдите на вкладку **⏰ Триггеры** — список пока пуст.
16. ![](screenshots/16.png) Нажмите «Добавить триггер»: функция `syncAndRefresh`, источник события «Триггер по времени», тип «По дням», время «23:00–0:00» → «Сохранить». **На этом шаге Google запросит разрешения для скрипта — это нормально, подтвердите доступ.**
17. ![](screenshots/17.png) Добавьте второй триггер тем же способом: функция `recordDailySnapshot`, тоже ежедневно, то же временное окно.
18. ![](screenshots/18.png) В списке триггеров теперь должно быть **2** записи — `syncAndRefresh` и `recordDailySnapshot`.
19. ![](screenshots/19.png) Вернитесь в редактор и на всякий случай пролистайте список файлов слева — убедитесь, что все ~20 файлов на месте.
20. ![](screenshots/20.png) Откройте саму Google Таблицу — в строке меню должен появиться новый пункт **Tinkoff**. Если он есть — установка прошла успешно.

### Этап 3. Заполнение Config (шаги 21–31)

21. ![](screenshots/21.png) В меню **Tinkoff → Настройки → Инициализировать Config** — создаётся лист «Настройки» с заготовками всех блоков.
22. ![](screenshots/22.png) Так выглядит свежесозданный Config: целевая структура портфеля, целевые доли акций, маппинг спецкатегорий, дивиденды, продвинутые параметры, цель портфеля — все поля пустые/дефолтные.
23. ![](screenshots/23.png) Заполните блок «Целевая структура портфеля»: проценты по категориям (например, Акции 60 / Облигации 25 / Золото 10 / Замещайки 0 / Денежный рынок 5) и названия счетов.
24. ![](screenshots/24.png) В меню **Tinkoff → Синхронизировать + обновить всё** — подтягиваются реальные позиции из Т-Инвестиций.
25. ![](screenshots/25.png) Через правый клик по ярлычкам листов внизу можно увидеть скрытые технические листы: `_Позиции`, `_Дан_Акции`, `_Дан_Облигации`, `_Дан_Фонды` и т.д. — в них реальные данные по вашим бумагам.
26. ![](screenshots/26.png) Откройте `_Дан_Акции` — там точные названия акций из вашего портфеля (это нужно для следующего шага).
27. ![](screenshots/27.png) Впишите эти названия **точно как в `_Дан_Акции`** в блок «Целевые доли акций» в Config (колонка «Тикер» — тикер соответствующей бумаги).
28. ![](screenshots/28.png) Проверьте, что название и тикер (например, «Озон» / `OZON`) введены без опечаток.
29. ![](screenshots/29.png) Аналогично откройте `_Дан_Фонды`, чтобы найти точное название фонда золота и денежного рынка.
30. ![](screenshots/30.png) В `_Дан_Фонды` — например, `ВИМ – Фонд Золото` и `Денежный рынок` с их тикерами (`GOLD`, `TMON@`).
31. ![](screenshots/31.png) Заполните блок «Маппинг спецкатегорий» этими точными названиями (Золото → `ВИМ – Фонд Золото`, Денежный рынок → `Денежный рынок`), доцените целевые % по акциям и, если нужно, впишите целевую сумму портфеля в блок «Цель портфеля».

### Этап 4. Первое использование (шаги 32–39)

32. ![](screenshots/32.png) Config полностью заполнен — можно переходить к отчётам. Меню **Tinkoff → Дашборд и ребаланс** открыто для справки.
33. ![](screenshots/33.png) **Tinkoff → Доход и история → Обновить Календарь выплат.**
34. ![](screenshots/34.png) **Tinkoff → Доход и история → Обновить Историю операций** — это самый долгий запрос, наберитесь терпения.
35. ![](screenshots/35.png) Лист «История операций» заполнен реальными суммами (пополнения, купоны, дивиденды, сделки).
36. ![](screenshots/36.png) **Tinkoff → Отчёты** — отсюда можно сформировать годовой отчёт (Google Doc) или открыть HTML-дашборд.
37. ![](screenshots/37.png) HTML-дашборд открывается модальным окном: общая стоимость, XIRR, сравнение с IMOEX, круговая диаграмма по классам активов.
38. ![](screenshots/38.png) На листе «Ребалансировка» впишите сумму пополнения (например, 45 000 ₽) и запустите **Tinkoff → Дашборд и ребаланс → Пересчитать калькулятор пополнения**.
39. ![](screenshots/39.png) Калькулятор покажет, сколько и чего докупить, чтобы вернуться к целевым долям — с разбивкой по классам, по акциям и по лотам.

Готово — трекер настроен и работает.

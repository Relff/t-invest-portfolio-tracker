# Прокси для T-Invest API

## По умолчанию уже работает

С версии с интеграцией прокси Relferium **ничего настраивать не нужно**.

Запросы автоматически идут через `https://certs.relferium.ru/api/proxy`.
Это решает проблему с SSL-сертификатами Т-Банка для новичков.

---

## Если хочешь свой прокси

Два способа:

1. **В Script Properties** задай `PROXY_URL` со своим адресом
2. **Или** замени строку в коде:
   ```javascript
   const DEFAULT_PROXY_URL = 'https://твой-прокси.vercel.app/api/proxy';
   ```

---

## Зачем это нужно

Т-Банк перешёл на сертификаты НУЦ Минцифры РФ. Google Apps Script не даёт настроить доверенные сертификаты напрямую, поэтому прямое подключение может не работать.

Прокси Relferium решает эту проблему из коробки.
